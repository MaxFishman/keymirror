When a show can't stop, you run two playback machines. KeyMirror makes the second one follow the first — key for key, frame for frame — so a dead laptop never means a dead screen.

THE REDUNDANCY PROBLEM

Teleprompter operators, presentation booths, and live-event techs advance cues with the arrow keys and space bar. Keep a hot backup Mac running the same deck and you still have to drive it by hand. Miss a press and the two screens drift apart on air.

KeyMirror captures every arrow and space on the primary with a passive, system-wide tap and injects it into the backup — both keep responding to your presses, and neither app needs to be the focused window.

HOW IT WORKS

A secure link between two Macs on the same network.

One Mac sends, one receives. They find each other over Bonjour — no IP addresses to type — authenticate with a shared secret, then stream keystrokes with sub-millisecond round trips.

SENDER Primary Mac

Captures ← → ↑ ↓ and space system-wide with a passive tap. Your local playback still responds; the keys are forwarded in parallel.

RECEIVER Redundant Mac

Injects each key into whatever app is focused there. A heartbeat echoes back every second so the sender can show live latency.

CONNECTION HANDSHAKE — the secret never crosses the wire
01

Challenge

The receiver opens with a magic header and a random 16-byte challenge.

02

Prove it

The sender replies with HMAC-SHA256(secret, challenge) — never the secret itself.

03

Stream

On accept, keystrokes and a 1-second ping/pong flow over TCP_NODELAY.

WHAT'S IN THE BOX

Bonjour auto-discovery

The sender finds the receiver by name on the LAN. No IP addresses to type — though you can pin one with --host if you prefer.

Shared-secret auth

HMAC-SHA256 challenge-response. The secret itself never travels the wire.

Auto-reconnect

Sleep a Mac or blip the Wi-Fi and the sender reconnects on its own, with backoff.

Pause hotkey

Press ⌃⌥⌘P to type locally without it reaching the backup. Press again to resume.

Menu-bar app

A ⌨ icon runs quietly in the background — pick a mode, watch status, grant permissions, all without a terminal.

In-app auto-updates

Checks GitHub Releases on launch. One click downloads, swaps itself in place, and relaunches.

GET RUNNING IN FIVE MINUTES

Install on both Macs, set one secret, pick a mode.

Grab the app, or drive the same binary from the command line. Do it on both machines — Receiver on the one being controlled, Sender on the one you type on.

THE APPmenu-bar, no terminal needed
install.command
# Unzip KeyMirror.zip from the latest release, then:
$ mv ~/Downloads/KeyMirror.app /Applications/
$ xattr -dr com.apple.quarantine \
    /Applications/KeyMirror.app
$ open /Applications/KeyMirror.app
⌨  icon appears in the menu bar ✓

The xattr step clears Gatekeeper because the app is ad-hoc signed. Or just run the bundled install.sh, which does all three. Grant Accessibility, Input Monitoring and Local Network when asked.

UNDER THE HOOD

A tiny, fixed-frame protocol.

After the handshake, three framed message types carry everything: the keys you press, and a ping/pong pair that measures the link. No dependencies, no cloud, nothing leaves your network.

KEY
keyCode · down · isRepeat — sender → receiver
PING
uint64 monotonic ns — every 1s
PONG
same value echoed — receiver → sender, for RTT
